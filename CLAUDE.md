# GlobeHouse Interactive — project guide for Claude

Local-only file (excluded via .git/info/exclude, never pushed to client repo).
Full history: notes/HISTORY.md. Read it at session start.

## Goal
Rebuild Dave's Base44 app "GlobeHouse Immersive AR" (live at globehouse-ar.com) as an
owned codebase on GitHub + Supabase + Vercel, matching its look and behavior exactly.
Then launch on www.GHITV.com and maintain monthly.

## Stack
- Vite 5 + React 18 + react-router-dom 6 + Tailwind 3 + lucide-react + @tanstack/react-query
- Supabase JS client: src/lib/supabase.js (exports `supabase`, `isSupabaseConfigured`)
- `@` alias = ./src (vite.config.js)
- Theme: bg #120e0a, card #1a1410/#241c15, text #EDE3D0, gold #D4AF37 / #B89045,
  fonts Playfair Display (`font-display`) + Inter (`font-sans`)

## Layout
- src/main.jsx — shows MissingConfig screen if env vars missing, else <App/>
- src/App.jsx — routes: / Dashboard, /marketplace, /player?id=, /mapper, /ubpl-editor
- src/components/Layout.jsx — header nav, auth state, footer
- src/components/ui/button.jsx — minimal shadcn-style Button replacement
- vercel.json — SPA rewrite to /index.html

## Commands
- npm install / npm run dev / npm run build
- Deploy prod: `vercel deploy --prod --yes --scope globe-house`
  (GitHub auto-deploy into globe-house team NOT connected yet)
- Supabase CLI: project ref `ohfjvvllqlkbxduslypl`

## Env vars (.env.local, gitignored)
VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY. Never use service_role key in frontend.

## Supabase
- Base44 entities: supabase/migrations/20261111000000_base44_entities.sql (generated by scripts/gen-schema.py).
  Old empty tables episodes/products/video_object_mappings are unused (locked, no policies).
- Tables added after the port go in src/api/entity-extensions.json (copy to supabase/functions/_shared/), never
  in the generated entity-*.json files.
- Viewer tiers (branch viewer-tiers): migration 20261114000000_viewer_tiers.sql, src/lib/viewerAccess.js,
  src/components/tiers/, pages Subscribe / Vault / Monetization, fns createCheckoutSession / createBillingPortalSession.
  Locked episodes' video links live in episode_media (RLS), merged back into episodes by both shims.
- Always deploy stripeWebhook with --no-verify-jwt.

## Rules
- Push to main = goes live (Dave's personal Vercel project also builds from main).
- Don't commit node_modules, dist, .env*, .vercel.
- Base44 is the reference: copy its pages/features/look faithfully.
